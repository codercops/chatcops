Tools extend the AI's capabilities by letting it perform actions like capturing leads, querying databases, or calling APIs.

## Built-in: Lead Capture

The `LeadCaptureTool` lets the AI collect contact information from conversations:

```typescript
import { LeadCaptureTool } from '@chatcops/core';

const leadTool = new LeadCaptureTool(async (lead) => {
  console.log('New lead:', lead);
  // Save to database, CRM, send webhook, etc.
});
```

### LeadData Shape

```typescript
interface LeadData {
  name: string;
  email: string;
  company?: string;
  phone?: string;
  projectDetails: string;
  source: string;
  metadata?: Record<string, unknown>;
}
```

The tool has these parameters:

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `name` | string | Yes | Full name |
| `email` | string | Yes | Email address |
| `company` | string | No | Company name |
| `phone` | string | No | Phone number |
| `projectDetails` | string | Yes | Summary of needs |

## ChatTool Interface

Create custom tools by implementing the `ChatTool` interface:

```typescript
interface ChatTool {
  name: string;          // letters, digits, _ and -, starting with a letter or _ (64 at most)
  description: string;
  inputSchema?: JSONSchema;                     // preferred: JSON Schema, root type 'object'
  parameters?: Record<string, ToolParameter>;   // the older flat form
  required?: string[];                          // with parameters only
  annotations?: { title?: string; readOnlyHint?: boolean; destructiveHint?: boolean };
  execute(input: Record<string, unknown>, context?: ToolContext): Promise<ToolResult>;
}

interface ToolContext {
  conversationId: string;
  signal: AbortSignal;   // aborts when the visitor leaves; pass it to fetch()
}

interface ToolResult {
  success: boolean;
  data?: unknown;
  message?: string;
}
```

The server checks every tool when it starts and throws a `ToolDefinitionError` listing what's wrong (an invalid or duplicate name, a schema whose root isn't an object, both `inputSchema` and `parameters` set), so a mistake shows up at boot instead of on the first message.

## Custom Tool Example

`inputSchema` takes any JSON Schema with an object at the root: nested objects, arrays, `enum`, `anyOf` and `$ref` work with Claude, OpenAI and Gemini.

```typescript
import type { ChatTool } from '@chatcops/core';

const orderTool: ChatTool = {
  name: 'place_order',
  description: 'Place an order for one or more products',
  inputSchema: {
    type: 'object',
    properties: {
      email: { type: 'string', description: 'Customer email' },
      items: {
        type: 'array',
        minItems: 1,
        items: {
          type: 'object',
          properties: {
            sku: { type: 'string' },
            qty: { type: 'integer', minimum: 1 },
          },
          required: ['sku', 'qty'],
        },
      },
    },
    required: ['email', 'items'],
  },

  async execute(input, context) {
    const response = await fetch('https://shop.example.com/api/orders', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(input),
      signal: context?.signal,
    });
    const order = await response.json();
    return { success: true, data: order, message: `Order ${order.id} placed` };
  },
};

// Use in server config
chatcopsMiddleware({
  provider: { type: 'claude', apiKey: '...' },
  systemPrompt: 'Help customers order products.',
  tools: [orderTool],
});
```

The model fills in the input, so check it in `execute` before acting on it, the way `LeadCaptureTool` does with zod.

### The flat parameters form

Tools written for earlier versions keep working. `parameters` is a flat map of string, number and boolean fields, converted to the same JSON Schema:

```typescript
const weatherTool: ChatTool = {
  name: 'get_weather',
  description: 'Get current weather for a city',
  parameters: {
    city: { type: 'string', description: 'City name' },
    unit: { type: 'string', description: 'Temperature unit', enum: ['celsius', 'fahrenheit'] },
  },
  required: ['city'],
  async execute(input) {
    const response = await fetch(`https://api.weather.example.com/${input.city}`);
    return { success: true, data: await response.json() };
  },
};
```

## How Tools Work

1. The AI decides when to call a tool based on conversation context
2. ChatCops converts tool definitions to the provider's native format
3. When the AI invokes a tool, `execute()` runs server-side
4. The result is fed back to the AI, which formulates a response
5. Tool calls are transparent to the user — they only see the final message
