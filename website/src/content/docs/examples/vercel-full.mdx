A production-ready Vercel Edge Function with lead capture, knowledge base, and analytics.

## API Route (`api/chat.ts`)

```typescript
import { chatcopsVercelHandler } from '@chatcops/server';
import { LeadCaptureTool, FAQKnowledgeSource } from '@chatcops/core';

export const config = { runtime: 'edge' };

export default chatcopsVercelHandler({
  provider: {
    type: 'claude',
    apiKey: process.env.ANTHROPIC_API_KEY!,
    model: 'claude-haiku-5-5',
  },

  systemPrompt: `You are a helpful AI assistant for our SaaS product.
    Answer questions about features, pricing, and getting started.
    If a user shares contact info, capture it with the lead tool.`,

  tools: [
    new LeadCaptureTool(async (lead) => {
      // Send to webhook (e.g., Zapier, Make, n8n)
      await fetch(process.env.WEBHOOK_URL!, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          type: 'lead_captured',
          lead,
          timestamp: new Date().toISOString(),
        }),
      });
    }),
  ],

  knowledge: [
    new FAQKnowledgeSource([
      { question: 'What is your pricing?', answer: 'Starter: Free, Pro: $29/mo, Enterprise: Custom.' },
      { question: 'Is there a free trial?', answer: 'Yes, 14-day free trial on all paid plans.' },
      { question: 'What integrations do you support?', answer: 'Slack, Discord, Zapier, webhooks, and REST API.' },
    ]),
  ],

  allowedOrigins: ['*'],
  sessionSecrets: [process.env.CHATCOPS_SESSION_SECRET!],
  analytics: true,
});
```

Add `api/chat/session.ts` with `export { default, config } from '../chat';`, so `/api/chat/session`, where the widget gets its session token, reaches the same handler.

## Next.js Integration

If using Next.js, place the file at `app/api/chat/route.ts`:

```typescript
import { chatcopsVercelHandler } from '@chatcops/server';

export const runtime = 'edge';

const handler = chatcopsVercelHandler({
  provider: {
    type: 'openai',
    apiKey: process.env.OPENAI_API_KEY!,
  },
  systemPrompt: 'You are a helpful assistant.',
  allowedOrigins: ['*'],
  sessionSecrets: [process.env.CHATCOPS_SESSION_SECRET!],
});

export const POST = handler;
// The handler answers the CORS preflight, so a widget on another origin needs OPTIONS too.
export const OPTIONS = handler;
```

Then `app/api/chat/session/route.ts`, for the session token: `export { POST, OPTIONS } from '../route';`.

More runtimes (Hono, Bun, Deno) are in [Next.js, Hono, Bun and Deno](/server/fetch-runtimes/).

## Widget in Next.js Layout

```tsx
// app/layout.tsx
import Script from 'next/script';

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        {children}
        <Script
          src="https://cdn.jsdelivr.net/npm/@chatcops/widget/dist/chatcops.min.js"
          data-api-url="/api/chat"
          data-accent="#6366f1"
          data-brand-name="Support"
          strategy="lazyOnload"
        />
      </body>
    </html>
  );
}
```

## Environment Variables

Set in Vercel dashboard → Settings → Environment Variables:

```bash
ANTHROPIC_API_KEY=sk-ant-...
CHATCOPS_SESSION_SECRET=...   # openssl rand -base64 32
WEBHOOK_URL=https://hooks.zapier.com/...
```
