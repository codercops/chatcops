The Express adapter wraps the ChatCops handler as Express middleware.

## Basic Setup

```typescript
import express from 'express';
import { chatcopsMiddleware } from '@chatcops/server';

const app = express();
app.use(express.json());

app.use('/chat', chatcopsMiddleware({
  provider: {
    type: 'claude',
    apiKey: process.env.ANTHROPIC_API_KEY!,
    model: 'claude-haiku-5-5',
  },
  systemPrompt: `You are a helpful customer support assistant for our website.
    Be concise, friendly, and helpful. If the user wants to contact us,
    use the lead capture tool to collect their information.`,
  allowedOrigins: ['*'],
  sessionSecrets: [process.env.CHATCOPS_SESSION_SECRET!],
  rateLimit: { maxRequests: 30, windowMs: 60_000 },
  analytics: true,
}));

const PORT = process.env.PORT ?? 3001;
app.listen(PORT, () => {
  console.log(`ChatCops server running on http://localhost:${PORT}`);
});
```

:::note
Mount the handler with `app.use('/chat', handler)`. That lets `OPTIONS` preflights from other origins reach it, and `/chat/session`, where the widget gets its session token. `app.all('/chat', ...)` would miss the session path. Generate `CHATCOPS_SESSION_SECRET` with `openssl rand -base64 32`.
:::

### Behind a proxy

Rate limits and the per-IP budget use `req.ip`. Behind a reverse proxy or a load balancer, `req.ip` is the proxy's address unless you tell Express to trust it, and then every visitor shares one limit. With one proxy in front:

```typescript
import express from 'express';

const app = express();
app.set('trust proxy', 1);
```

The server logs a warning when requests carry `X-Forwarded-For` but `trust proxy` is off. Don't set it to `true` unless every request comes through your proxy: Express would then believe any `X-Forwarded-For` a visitor sends.

## With Lead Capture

```typescript
import { LeadCaptureTool } from '@chatcops/core';
import express from 'express';
import { chatcopsMiddleware } from '@chatcops/server';

const app = express();
const db = { leads: { create: async (_lead: unknown) => {} } };

app.use('/chat', chatcopsMiddleware({
  provider: {
    type: 'claude',
    apiKey: process.env.ANTHROPIC_API_KEY!,
  },
  systemPrompt: 'You are a helpful assistant. Capture leads when users share contact info.',
  tools: [
    new LeadCaptureTool(async (lead) => {
      // Save to your database, CRM, etc.
      await db.leads.create(lead);
      console.log('Lead captured:', lead.email);
    }),
  ],
}));
```

## With Knowledge Base

```typescript
import { FAQKnowledgeSource, TextKnowledgeSource } from '@chatcops/core';
import express from 'express';
import { chatcopsMiddleware } from '@chatcops/server';

const app = express();

app.use('/chat', chatcopsMiddleware({
  provider: { type: 'openai', apiKey: process.env.OPENAI_API_KEY! },
  systemPrompt: 'Answer questions using the provided context.',
  knowledge: [
    new FAQKnowledgeSource([
      { question: 'What are your hours?', answer: '9am-5pm EST, Monday-Friday.' },
      { question: 'Do you offer refunds?', answer: 'Yes, within 30 days of purchase.' },
    ]),
    new TextKnowledgeSource([
      'Our company was founded in 2020. We specialize in AI solutions...',
    ]),
  ],
}));
```

## Express Compatibility

The adapter works with both Express 4.x and 5.x. Express is listed as an optional peer dependency — install it separately:

```bash
npm install express @chatcops/server
```
