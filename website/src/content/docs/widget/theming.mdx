---
title: Theming
description: Customize the ChatCops widget appearance to match your brand.
---

ChatCops uses a theme engine that applies CSS custom properties to the Shadow DOM host element.

## Theme Configuration

```typescript
ChatCops.init({
  apiUrl: '/api/chat',
  theme: {
    accent: '#6366f1',           // Primary color for buttons, user messages
    textColor: '#FAFAF9',        // Main text color
    bgColor: '#0A0A0A',          // Widget background
    fontFamily: 'Inter, sans-serif',
    borderRadius: 12,            // px if a number, or any CSS length like '1rem'
    position: 'bottom-right',    // or 'bottom-left'
  },
});
```

## Color Manipulation

The theme engine derives hover and surface colors from the colors you pass:

- **Accent hover:** Darkened by 10% from `accent`
- **Surface:** Lightened by 8% from `bgColor`
- **Input:** Lightened by 14% from `bgColor`

## Built-in Dark Theme

The default theme is optimized for dark mode:

| Element | Color |
|---------|-------|
| Background | `#0a0a0a` |
| Surface | `#1a1a1a` |
| Input area | `#2a2a2a` |
| Border | `#333333` |
| Text | `#ffffff` |
| Secondary text | `#a0a0a0` |
| Accent | `#6366f1` (indigo) |
| Accent hover | `#4f46e5` |

## Light Theme Example

```typescript
ChatCops.init({
  apiUrl: '/api/chat',
  theme: {
    accent: '#4f46e5',
    textColor: '#1a1a1a',
    bgColor: '#ffffff',
    borderRadius: 16,
  },
});
```

## CSS Override (Advanced)

You can override widget styles by targeting the host element. The first widget on a page has the id `chatcops-root`, and every widget host has the class `chatcops-root`, so use `.chatcops-root` to style all of them:

```css
#chatcops-root {
  --cc-accent: #e11d48;
  --cc-bg: #ffffff;
  --cc-text: #111111;
  --cc-panel-width: 450px;
  --cc-panel-height: 600px;
  --cc-fab-size: 64px;
}
```

## ThemeConfig Interface

```typescript
interface ThemeConfig {
  accent?: string;          // Hex color
  textColor?: string;       // Hex color
  bgColor?: string;         // Hex color
  fontFamily?: string;      // CSS font-family string
  borderRadius?: string | number;  // px if a number or numeric string (12, '12'), or any CSS length ('1rem')
  position?: 'bottom-right' | 'bottom-left';
}
```

## Position

The widget supports two positions:

- `bottom-right` (default) — FAB and panel anchored to bottom-right
- `bottom-left` — FAB and panel anchored to bottom-left

On mobile screens, the chat panel always goes full-screen regardless of position.
