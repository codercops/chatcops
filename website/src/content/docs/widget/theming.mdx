title: Theming
description: Customize the ChatCops widget appearance to match your brand.

ChatCops uses a theme engine that applies CSS custom properties to the Shadow DOM host element.

## Light, dark and auto

The widget has a light and a dark look. By default (`mode: 'auto'`) it follows the visitor's system setting, and switches while the page is open when that setting changes. Pin one with `mode`:

```typescript
ChatCops.init({
  apiUrl: '/api/chat',
  theme: {
    mode: 'light',               // 'light', 'dark' or 'auto' (the default)
    accent: '#4f46e5',           // buttons, the launcher, visitor messages
    accentDark: '#a5b4fc',       // the accent in dark mode; defaults to accent
    fontFamily: 'Inter, sans-serif',
    borderRadius: 12,            // px if a number, or any CSS length like '1rem'
    position: 'bottom-right',    // or 'bottom-left'
  },
});
```

On the script tag, these are `data-theme-mode`, `data-accent` and `data-accent-dark`.

| Element | Light | Dark |
|---------|-------|------|
| Background | `#ffffff` | `#0a0a0a` |
| Surface (bot messages, header) | `#f4f5f7` | `#1a1a1a` |
| Input area | `#ffffff` | `#2a2a2a` |
| Border | `#d9dce1` | `#333333` |
| Text | `#1a1d23` | `#ffffff` |
| Secondary text | `#5b616e` | `#a0a0a0` |
| Accent | `#4f46e5` | `#6366f1` |
| Errors | `#c62828` | `#ef4444` |

The dark look is the one the widget had before light mode existed. Text on the accent is picked for contrast (white or near-black, with the accent darkened a little when neither reaches 4.5:1), in each mode for its own accent.

### Upgrading from a dark-only version

Earlier versions of the widget were always dark. Now it's light on light systems, which suits most sites better. To keep the old look everywhere, set `mode: 'dark'` (or `data-theme-mode="dark"`).

If your config sets `bgColor` or `textColor` and no `mode`, the widget picks the mode those colors were made for: a dark `bgColor` or a light `textColor` means dark, so a custom dark theme keeps working as it was.

## Custom colors

`bgColor` and `textColor` replace the background and text in every mode, and the theme engine derives the other surfaces from them:

- **Surface:** lightened by 8% from `bgColor`
- **Input:** lightened by 14% from `bgColor`
- **Accent hover:** darkened by 10% from `accent` (and from `accentDark`)

```typescript
ChatCops.init({
  apiUrl: '/api/chat',
  theme: {
    accent: '#e11d48',
    textColor: '#FAFAF9',
    bgColor: '#18181b',
  },
});
```

## CSS Override (Advanced)

You can override widget styles by targeting the host element. The first widget on a page has the id `chatcops-root`, and every widget host has the class `chatcops-root`, so use `.chatcops-root` to style all of them:

```css
#chatcops-root {
  --cc-accent: #e11d48;
  --cc-bg: #ffffff;
  --cc-text: #111111;
  --cc-panel-width: 450px;
  --cc-panel-height: 600px;
  --cc-fab-size: 64px;
}
```

## AI-generated replies

Replies written by the model carry `data-ai-generated="true"`. User messages and the welcome message don't. The messages are inside the widget's shadow root, so the page's CSS can't select them, but scripts can:

```js
document.getElementById('chatcops-root').shadowRoot.querySelectorAll('[data-ai-generated]');
```

## ThemeConfig Interface

```typescript
interface ThemeConfig {
  mode?: 'light' | 'dark' | 'auto';  // Default 'auto': follows the system setting
  accent?: string;          // Hex color
  accentDark?: string;      // Hex color, the accent in dark mode. Defaults to accent
  textColor?: string;       // Hex color
  bgColor?: string;         // Hex color
  fontFamily?: string;      // CSS font-family string
  borderRadius?: string | number;  // px if a number or numeric string (12, '12'), or any CSS length ('1rem')
  position?: 'bottom-right' | 'bottom-left';
}
```

## Position

The widget supports two positions:

- `bottom-right` (default) — FAB and panel anchored to bottom-right
- `bottom-left` — FAB and panel anchored to bottom-left

On mobile screens, the chat panel always goes full-screen regardless of position.
