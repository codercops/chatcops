The ChatCops widget emits events you can listen to for analytics, custom behavior, or integration with your app.

## Subscribing to Events

You can register event handlers with `ChatCops.on()`. Handlers can be registered before calling `ChatCops.init()` (including in inline scripts before `DOMContentLoaded`), and are preserved across repeated `init()` calls.

`ChatCops.on()` returns an unsubscribe function that removes the handler from both the persistent registry and the active widget instance:

```typescript
// Subscribe to an event
const unsub = ChatCops.on('open', () => {
  console.log('Chat opened');
});

// Unsubscribe later
unsub();
```

Alternatively, you can unregister a handler with `ChatCops.off()`:

```typescript
function onOpen() {
  console.log('Chat opened');
}

ChatCops.on('open', onOpen);
ChatCops.off('open', onOpen);
```

## Event Types

### `open`

Fired when the chat panel opens. Takes no arguments.

```typescript
ChatCops.on('open', () => {
  analytics.track('chat_opened');
});
```

### `close`

Fired when the chat panel closes. Takes no arguments.

```typescript
ChatCops.on('close', () => {
  analytics.track('chat_closed');
});
```

### `message`

Fired when a message is sent or received.

Payload: `{ id, role, content, status?, errorType? }`

- `id`: `string` - Unique identifier for the message.
- `role`: `'user' | 'assistant'` - The sender role.
- `content`: `string` - The message text content.
- `status`: `'streaming' | 'complete' | 'error'` (optional) - Delivery status of the message.
- `errorType`: `'rate_limit' | 'network' | 'provider_error' | 'timeout'` (optional) - Error category when status is `'error'`.

```typescript
ChatCops.on('message', (message) => {
  console.log(`${message.role}: ${message.content}`);
});
```

### `error`

Fired when an error occurs. Emits a plain JavaScript `Error` instance.

Payload: `Error`

```typescript
ChatCops.on('error', (error) => {
  console.error('Chat error:', error.message);
});
```

### `leadCaptured`

Fired when lead data is captured during a chat session.

Payload: `leadData?: Record<string, unknown>`

```typescript
ChatCops.on('leadCaptured', (leadData) => {
  console.log('Lead captured:', leadData);
});
```

### `preChatSubmit`

Fired when a user submits the pre-chat form before starting a conversation.

Payload: `data: Record<string, string>`

```typescript
ChatCops.on('preChatSubmit', (data) => {
  console.log('Pre-chat form submitted:', data);
});
```

## Use Cases

### Analytics Integration

```typescript
ChatCops.on('open', () => {
  gtag('event', 'chat_widget_open');
});

ChatCops.on('message', (data) => {
  if (data.role === 'user') {
    gtag('event', 'chat_message_sent');
  }
});
```

### Custom Triggers

Open the chat when a user clicks a help button:

```typescript
document.querySelector('#help-btn').addEventListener('click', () => {
  ChatCops.open();
});
```

### Conditional Display

```typescript
// Only show chat on certain pages
if (window.location.pathname.startsWith('/support')) {
  ChatCops.init({ apiUrl: '/api/chat' });
}
```
