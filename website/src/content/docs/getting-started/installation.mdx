---
title: Installation
description: Install ChatCops packages via npm, CDN, or ESM imports.
---

ChatCops consists of three packages. Install only what you need.

## Widget (Client-Side)

### CDN (Recommended)

The simplest way, with no build step:

```html
<script
  src="https://cdn.jsdelivr.net/npm/@chatcops/widget@1/dist/chatcops.min.js"
  data-api-url="https://your-api.com/chat"
></script>
```

`@1` in the URL gets every 1.x release, with fixes and new features, but never 2.0, whose breaking changes wait for you to upgrade. Pin an exact version (`@1.0.0`) to change nothing until you choose to. A URL without a version follows npm's `latest`, so a new major reaches your site the day it's published.

`chatcops.min.js` is a small loader (under 5 kB gzipped) that draws the chat button. The rest of the chat (`chatcops.panel.js`, next to it) downloads when the visitor hovers or clicks the button, or when the chat has to open on its own. So pages where nobody opens the chat only pay for the button. Parts that only some sites use, the pre-chat form and Turnstile, are separate files in `dist/chunks/` and download only on sites that turn them on.

### Self-hosting

To serve the widget from your own site, copy `dist/chatcops.min.js`, `dist/chatcops.panel.js` and the `dist/chunks/` folder into the same folder. The loader finds the panel next to itself, and the panel finds its chunks. If you can only serve one file, use `dist/chatcops.full.min.js` instead: the whole chat in one script, loaded up front. A Content Security Policy needs the folder's origin in `script-src` either way.

### npm

For bundler-based projects (Vite, webpack, Next.js):

```bash
npm install @chatcops/widget
```

```typescript
import ChatCops from '@chatcops/widget';

ChatCops.init({
  apiUrl: 'https://your-api.com/chat',
  theme: { accent: '#6366f1' },
  branding: { name: 'My Assistant' },
});
```

## Server

```bash
npm install @chatcops/server
```

The server package includes adapters for Express, Vercel, and Cloudflare Workers:

```typescript
// Express
import { chatcopsMiddleware } from '@chatcops/server';

// Vercel Edge
import { chatcopsVercelHandler } from '@chatcops/server';

// Cloudflare Workers
import { chatcopsCloudflareHandler } from '@chatcops/server';
```

## Core (Optional)

Only needed if building custom integrations:

```bash
npm install @chatcops/core
```

Provides direct access to providers, tools, knowledge base, and i18n:

```typescript
import { createProvider, LeadCaptureTool, FAQKnowledgeSource } from '@chatcops/core';
```

## Requirements

- **Widget:** Any modern browser (Chrome, Firefox, Safari, Edge)
- **Server:** Node.js 22+ (Express), or edge runtime (Vercel/Cloudflare)
- **TypeScript:** Full type definitions included in all packages
